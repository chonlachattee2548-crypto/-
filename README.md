# Jewelry Gem Stone (ระบบแสดงและจัดการอัญมณี)

เว็บแอปต้นแบบสำหรับโครงงาน Jewelry Gem Stone อ้างอิงเอกสารสัปดาห์ที่ 2–6 และเอกสารรายละเอียดหน้าจอฉบับแก้ไขของสัปดาห์ที่ 7

## วิธีเปิดใช้งาน

ไม่ต้องติดตั้งส่วนเสริมหรือสั่งประกอบโปรแกรม เปิด PowerShell ในโฟลเดอร์นี้แล้วรัน:

```powershell
py -m http.server 4173
```

จากนั้นเปิด <http://localhost:4173>

## เผยแพร่เว็บไซต์ให้คนอื่นเปิดดู

โครงการนี้ตั้งค่า GitHub Pages ไว้แล้ว เมื่อส่งไฟล์ขึ้น repository สาธารณะ ระบบจะเผยแพร่เว็บไซต์ให้อัตโนมัติ โดยไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build

1. ลงชื่อเข้าใช้ GitHub แล้วสร้าง repository ใหม่ โดยเลือก **Public** และอย่าสร้าง README, License หรือไฟล์เริ่มต้นซ้ำ
2. ใน GitHub เปิด **Settings > Emails** แล้วคัดลอกอีเมล `noreply` ที่ GitHub ให้มา เพื่อไม่ให้อีเมลส่วนตัวติดไปกับประวัติ commit
3. เปิด PowerShell ในโฟลเดอร์โครงการ แล้วแทนที่ `ชื่อผู้ใช้`, `ชื่อคลัง` และ `อีเมล-noreply-จาก-GitHub` ในคำสั่งต่อไปนี้ให้ตรงกับบัญชีและ repository ที่สร้าง

```powershell
git init -b main
git config user.email "อีเมล-noreply-จาก-GitHub"
git add .
git commit -m "เริ่มต้นเว็บอัญมณี"
git remote add origin https://github.com/ชื่อผู้ใช้/ชื่อคลัง.git
git push -u origin main
```

4. ในหน้า repository เปิด **Settings > Pages** แล้วตั้ง **Build and deployment > Source** เป็น **GitHub Actions**
5. เปิดแท็บ **Actions** และรอ workflow ชื่อ **เผยแพร่เว็บบน GitHub Pages** ทำงานเสร็จ ลิงก์เว็บไซต์จะอยู่ใน **Settings > Pages** โดยปกติมีรูปแบบ `https://ชื่อผู้ใช้.github.io/ชื่อคลัง/`

เมื่อแก้ไฟล์แล้วส่งขึ้น branch `main` อีกครั้ง เว็บไซต์จะอัปเดตให้อัตโนมัติ ไฟล์ทั้งหมดใน repository นี้จะเปิดดูได้สาธารณะด้วย

## โมดูลที่มีในแอป

- **ตู้โชว์อัญมณี**: แสดงสถานะกล้องและอุปกรณ์ตามจริง ปุ่มหมุนจะไม่รายงานว่าสำเร็จเมื่อยังไม่ได้เชื่อมต่อฮาร์ดแวร์
- **แคตตาล็อกอัญมณี**: ค้นหา กรอง ดูรายละเอียดและสถานะสินค้า พร้อมบันทึกเหตุการณ์เปิดดู
- **ระบบสมาชิก**: สมัครสมาชิก เข้าสู่ระบบ ล็อกบัญชีเมื่อกรอกรหัสผิด และขั้นตอนจำลองการตั้งรหัสผ่านใหม่
- **จัดการร้าน**: เพิ่ม/แก้ไขสินค้า นำสินค้าออกจากการเผยแพร่ ปรับสต็อก และแก้ไขข้อความหน้าแรก
- **รายงาน**: เหตุการณ์ สต็อก การเข้าชม สินค้าที่ได้รับความสนใจ และประวัติสมาชิก พร้อมตัวกรองช่วงวันที่

ทุกหน้าจอและเอกสารประกอบเป็นภาษาไทย

## บัญชีผู้ดูแลสำหรับทดลอง

- อีเมล: `admin@gemstone.demo`
- รหัสผ่าน: `GemstoneDemo1!`

บัญชีนี้ใช้สำหรับทดลองระบบเท่านั้น ข้อมูลสินค้าและเหตุการณ์บันทึกในพื้นที่จัดเก็บของเบราว์เซอร์ กด **คืนค่าข้อมูลตัวอย่าง** ในส่วนผู้ดูแลเพื่อคืนรายการสินค้าเริ่มต้น

## ข้อจำกัดของต้นแบบ

แอปนี้เป็นต้นแบบที่ทำงานในเบราว์เซอร์ ยังไม่ใช่ระบบสำหรับใช้งานจริง ระบบสมาชิกและสิทธิ์ผู้ดูแลทำงานฝั่งเบราว์เซอร์ จึงไม่สามารถป้องกันการแก้ไขข้อมูลหรือปลอมสิทธิ์ได้ ห้ามใช้รหัสผ่านหรือข้อมูลส่วนบุคคลจริง

การใช้งานจริงต้องเพิ่มระบบยืนยันตัวตนและฐานข้อมูลฝั่งเซิร์ฟเวอร์ ระบบจัดเก็บรูปภาพ ระบบส่งอีเมล Cloudflare Stream และการเชื่อมต่อ Workers/WebSocket ที่มีการควบคุมสิทธิ์ไปยัง ESP32 และมอเตอร์ รวมถึงระบบรับข้อมูล PIR จากอุปกรณ์ แอปจะแสดงสถานะว่ายังไม่ได้เชื่อมต่อ และจะไม่สร้างภาพสด ผลการหมุน หรือข้อมูลเซนเซอร์ปลอมขึ้นมา
